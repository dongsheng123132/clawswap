# OpenClaw 产品交互设计文档

> 给 Cursor 的前端开发指南。请按此文档实现完整的用户体验。

---

## 0. 核心理念

**一句话**：用户用 Twitter 登录，30 秒内就能让 AI Agent 帮他在 Monad 上自动交易。

**不要**做成一堆分散的页面。**要**做成一个流畅的、有引导感的单页应用（类似 pump.fun / friend.tech 的体验）。

---

## 1. 整体页面结构

只有 **一个主页面**，通过 Tab 切换功能区域：

```
┌─────────────────────────────────────────────────────────┐
│  🐙 OpenClaw     [Swap] [Agent] [Earn]     [🔵 连接钱包] │  ← 顶栏
├─────────────────────────────────────────────────────────┤
│                                                         │
│                    主内容区域                             │
│              （根据 Tab 切换内容）                        │
│                                                         │
├─────────────────────────────────────────────────────────┤

└─────────────────────────────────────────────────────────┘
```

│     │  You pay                     Balance: 500 │        │

│     │  │  100         │  │ USDC         ▼   │  │        │
│     │  └──────────────┘  └──────────────────┘  │        │
│     │                                          │        │
│     │                  ⇅                       │        │
│     │                                          │        │
│     │  You receive                 Balance: 12  │        │

│     ✅ 0.5 MON → 0.2 USDC     1 小时前                  │
│                                                         │

└─────────────────────────────────────────────────────────┘

**交互细节：**
- 输入金额时实时获取报价（debounce 500ms）
- 代币选择器：点击 "USDC ▼" 弹出 modal，可搜索
- 点击 Swap → AA 钱包签名（Privy 弹窗 或 Session Key 静默签名）
- 交易提交后底部 toast 显示进度：发送中 → 确认中 → 完成
- Swap 按钮状态：未连接→"Connect Wallet" / 余额不足→"Insufficient Balance" / 正常→"Swap"

## 7. AI Agent 具体交易什么？（产品逻辑）

### 7.1 测试网上能做的事

| 场景 | 交易对 | 怎么做 |
|------|--------|--------|
| 定投 MON | USDC → MON | 每小时/每天自动买固定金额的 MON |
| 止盈止损 | MON → USDC | MON 涨到/跌到某价格自动卖 |
| 手动 Swap | 任意对 | 用户自己在 Swap 页面交易 |
| 自然语言交易 | 任意对 | "帮我买100U的MON" |

### 7.2 主网未来能做的事

| 场景 | 怎么做 | x402 集成 |
|------|--------|-----------|
| 新币狙击 | 监控 nad.fun 新币上线 → 符合条件自动买入 | 监控 API 可以卖给其他 Agent |
| 套利 | 发现 OpenClaw 和 Kuru 之间的价差 → 低买高卖 | — |
| 跟单交易 | 监控聪明钱地址 → 复制他们的交易 | 跟单信号 API 卖给其他 Agent |
| 代币发射 | 通过 nad.fun SDK 自动创建 meme 币 | 发币 API 卖给其他 Agent |

### 7.3 Agent 的交易决策流程

```
Agent 定时检查 (每 10 秒)
    │
    ├─ 定投策略: 到时间了吗？ → 是 → 获取报价 → 风控检查 → swap
    │
    ├─ 止盈止损: 当前价格触发了吗？ → 是 → 执行卖出
    │
    ├─ 新币狙击: nad.fun 有新币吗？
    │     → 检查创建者历史、初始流动性、社交热度
    │     → 符合条件 → 买入 X MON
    │
    └─ 用户指令: 有新的自然语言指令吗？ → 解析 → 执行
```

## 8. 技术实现要点

### 8.1 前端技术栈

```
Next.js 14 (App Router)
├── Privy (@privy-io/react-auth) — 社交登录 + 嵌入式钱包
├── wagmi + viem — 链交互
├── RainbowKit — 钱包连接 UI（给有钱包的用户）
├── Tailwind CSS — 样式
├── Framer Motion — 动画
└── shadcn/ui — UI 组件
```

### 8.2 页面路由

```
/ (根路由)
├── 未登录 → 显示全屏 Onboarding（登录页）
└── 已登录 → 显示主界面
    ├── Tab: Swap（默认）
    ├── Tab: Agent
    └── Tab: Earn
```

不要用多页面路由（/swap, /agent, /earn），用**客户端 Tab 切换**，体验更流畅。

### 8.3 状态管理

```typescript
// 全局状态（用 React Context 或 Zustand）
interface AppState {
  // 钱包
  wallet: {
    address: string;
    balances: { mon: bigint; usdc: bigint };
    isSmartWallet: boolean;
  };

  // Agent
  agent: {
    status: "inactive" | "running" | "paused";
    activeStrategies: Strategy[];
    sessionKeyExpiry: number | null;
    tradeHistory: Trade[];
    pnl: { totalCost: number; currentValue: number };
  };

  // x402 收益
  earnings: {
    today: number;
    total: number;
    apiCalls: { quote: number; swap: number; price: number };
  };
}
```

### 8.5 关键 API 端点

```
=== 免费端点（不需要 x402）===
POST /api/v1/auth/session-key    — 前端提交 Session Key
POST /api/v1/auth/revoke         — 撤销 Session Key
GET  /api/v1/agent/status        — Agent 状态
GET  /api/v1/agent/stream        — SSE 实时日志
POST /api/v1/agent/strategy      — 配置策略
GET  /api/v1/agent/history       — 交易历史
GET  /api/v1/price?token=MON     — 免费价格查询

=== 付费端点（x402 收费，给外部 Agent 用）===
GET  /api/v1/quote               — 报价 ($0.0001/次)
POST /api/v1/swap                — 执行交易 ($0.001/次)
```

## 9. 视觉风格

- **主题**: 纯黑背景 (#000)，深灰卡片 (#18181B)
- **强调色**: 紫色 (#7C3AED) — 按钮、高亮
- **成功**: 绿色 (#22C55E) — 盈利、成功交易
- **警告**: 橙色 (#F59E0B) — 跳过、等待
- **错误**: 红色 (#EF4444) — 亏损、失败
- **字体**: Inter，数字用等宽
- **圆角**: 卡片 24px，按钮 16px，输入框 12px
- **动画**: 数字变化用计数器动画，状态切换用 fade + slide

## 10. 移动端适配

所有布局移动端优先。主内容区最大宽度 480px 居中。Tab 栏在移动端变成底部导航。

## 11. Cursor 开发顺序

```
Step 1: 布局框架
  - 创建 layout（顶栏 + 底部余额条 + Tab 系统）
  - Privy 登录集成
  - Onboarding 全屏引导页
  - 登录后跳转主界面

Step 2: Swap Tab
  - 代币选择器组件
  - 报价 hook（调用 Quoter 合约 或 server API）
  - Swap 按钮逻辑（approve + swap）
  - 交易状态 toast
  - 最近交易列表

Step 3: Agent Tab — 策略配置
  - 策略选择卡片（DCA / 止盈止损 / 新币狙击 / 自然语言）
  - DCA 配置表单
  - 止盈止损配置表单
  - Session Key 签发流程
  - "启动 Agent" 按钮

Step 4: Agent Tab — 运行状态
  - Agent 状态指示器
  - 实时交易日志（SSE）
  - 持仓汇总 + PnL 计算
  - 暂停/停止/撤销按钮

Step 5: Agent Tab — 自然语言
  - 聊天式 UI
  - 发送指令 → 调用 Agent API
  - 显示 Agent 解析结果
  - 确认/取消交互

Step 6: Earn Tab
  - x402 API 统计面板
  - 收益数据展示
  - SDK 使用示例代码展示

Step 7: 测试网引导
  - 余额为 0 时显示引导
  - 水龙头链接
  - 刷新余额按钮

Step 8: 打磨
  - 动画效果
  - 移动端适配
  - Loading / Error / Empty 状态
  - 数字格式化（千分位、小数位）
```
